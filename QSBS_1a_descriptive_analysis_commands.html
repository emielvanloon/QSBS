QSBS R Reference — Commands for Descriptive Data Analysis

Introduction

This document summarizes the R commands and relevant command options used in the eight descriptive-data-analysis exercises. It can be used as a reference sheet while working through the practical.

The main concepts to remember

The commands can be organized into four broad groups.

1. Descriptive statistics

mean()
median()
sd()
var()
IQR()
quantile()
range()

These describe the location and variability of a variable.

2. Frequencies

table()
prop.table()
sort()

These are particularly useful for categorical variables and for examining frequency distributions.

3. Graphical exploration

hist()
boxplot()
rug()
density()
lines()

These help reveal features such as skewness, outliers, modality and spread.

4. Data selection and manipulation

$
[]
c()
round()

These allow you to extract variables, select observations, combine results and format numerical output.

The key principle throughout the practical is that numerical summaries and graphical summaries complement each other. A good descriptive analysis normally uses both.

Compact command reference

The following is a compact list of the main commands used in the practical.

# Load package
library(MASS)

# Documentation
?cats

# Location
mean(x)
mean(x, trim = 0.10)
median(x)

# Frequency / proportions
table(x)
prop.table(table(x))
sort(x, decreasing = TRUE)

# Variability
sd(x)
var(x)
IQR(x)
range(x)
diff(range(x))

# Quantiles
quantile(x)
quantile(x, c(0.25, 0.50, 0.75))

# Histogram
hist(x)
hist(x, breaks = 5)
hist(x, breaks = 20)
hist(x, probability = TRUE)

# Density and rug
density(x)
rug(x)
lines(density(x), lwd = 2)

# Boxplot
boxplot(x)
boxplot.stats(x)
boxplot.stats(x)$stats
boxplot.stats(x)$out

# Selecting observations
x[x < 45]
x[x > 45]
x[x == 45]

# Rounding
round(x, 1)

# Combining results
c(a = ..., b = ..., c = ...)

# Basic skewness
mean((x - mean(x))^3) / sd(x)^3

Loading and inspecting data

library()

Loads a package into the current R session.

library(MASS)

?

Opens the R documentation for a dataset or function.

?cats
?birthwt
?Melanoma
?UScereal

Measures of location

mean()

Calculates the arithmetic mean.

mean(x)

The trim option calculates a trimmed mean:

mean(x, trim = 0.10)

trim = 0.10 removes 10% of observations from each tail before calculating the mean.

median()

Calculates the median.

median(x)

c()

Combines values into a vector. Naming elements makes the output easier to interpret.

c(
  mean = mean(cats$Bwt),
  trimmed_mean_10 = mean(cats$Bwt, trim = 0.10),
  median = median(cats$Bwt)
)

Frequency tables

table()

Creates a frequency table.

table(x)

Examples:

table(cats$Sex)
table(cats$Bwt)

sort()

Sorts values.

sort(x, decreasing = TRUE)

decreasing = TRUE puts the largest values first.

max()

Returns the largest value.

max(x)

For example, to find the highest frequency:

max(table(cats$Bwt))

Logical indexing

Square brackets can select elements satisfying a condition.

bwt_freq <- table(cats$Bwt)

max_freq <- max(bwt_freq)

bwt_freq[bwt_freq == max_freq]

The expression

bwt_freq == max_freq

produces TRUE or FALSE values, and [ ] selects the elements for which the result is TRUE.

Proportions

prop.table()

Converts a frequency table into proportions.

prop.table(table(x))

For example:

prop.table(table(cats$Sex))

A particular category can be selected by name:

prop.table(table(cats$Sex))["F"]

Convert proportions to percentages:

100 * prop.table(table(cats$Sex))

Round them:

round(100 * prop.table(table(cats$Sex)), 1)

Measures of variability

sd()

Calculates the sample standard deviation.

sd(x)

var()

Calculates the sample variance.

var(x)

IQR()

Calculates the interquartile range:

\[ IQR = Q_3 - Q_1 \]

IQR(x)

range()

Returns the minimum and maximum.

range(x)

The width of the range can be calculated with diff():

diff(range(x))

Quantiles and five-number summaries

quantile()

By default, quantile() returns the minimum, Q1, median, Q3 and maximum.

quantile(x)

Particular quantiles can be requested:

quantile(x, c(0.25, 0.50, 0.75))

The probabilities correspond to:

  • 0.25 → first quartile (Q1)
  • 0.50 → median
  • 0.75 → third quartile (Q3)

Histograms

hist()

Creates a histogram.

hist(x)

breaks

Controls the number or positions of histogram breaks.

hist(x, breaks = 5)
hist(x, breaks = 20)

Few breaks can oversmooth a distribution, whereas many breaks can undersmooth it.

probability

Scales the histogram as a density/probability histogram.

hist(x, probability = TRUE)

This is useful when a density curve is to be added to the histogram.

xlab, ylab, and main

Control axis labels and the plot title.

hist(
  x,
  xlab = "Survival time (days)",
  ylab = "Density",
  main = "Distribution of survival time"
)
Option Purpose
breaks Histogram breaks
probability Plot density/probability rather than frequency
xlab x-axis label
ylab y-axis label
main Plot title

Rug plots

rug()

Adds a mark for each observation along an axis.

rug(x)

For example:

rug(Melanoma$time)

A rug plot is useful for showing where the individual observations occur.

Kernel density estimates

density()

Calculates a kernel density estimate.

density(x)

lines()

Adds a line to an existing plot.

lines(density(x), lwd = 2)

lwd controls line width.

A typical combination is:

hist(
  Melanoma$time,
  probability = TRUE,
  xlab = "Survival time (days)",
  ylab = "Density"
)

rug(Melanoma$time)

lines(
  density(Melanoma$time),
  lwd = 2
)

Boxplots

boxplot()

Creates a boxplot.

boxplot(x)

Useful options include:

boxplot(
  x,
  ylab = "Value",
  main = "Boxplot"
)
Option Purpose
ylab y-axis label
main Plot title

boxplot.stats()

Returns statistics used to construct a boxplot.

box_stats <- boxplot.stats(x)

box_stats$stats
box_stats$out

Important components:

Component Meaning
$stats Lower whisker, Q1, median, Q3, upper whisker
$out Boxplot-defined outliers
$n Number of observations
$conf Confidence interval for the median

The boxplot outlier rule

An observation is classified as a boxplot outlier if it lies below

\[ Q_1 - 1.5 \times IQR \]

or above

\[ Q_3 + 1.5 \times IQR. \]

The fences can be calculated explicitly:


q <- quantile(x, c(0.25, 0.50, 0.75))
iqr <- IQR(x)

lower_fence <- q[1] - 1.5 * iqr
upper_fence <- q[3] + 1.5 * iqr

c(
  lower_fence = lower_fence,
  upper_fence = upper_fence
)

Selecting observations

The general form is:

x[condition]

Examples:

x[x < 45]
x[x > 45]
x[x == 45]
x[x != 45]

For the birthwt example:

age_without_outlier <- birthwt$age[birthwt$age < 45]

Logical operators

Operator Meaning
< Smaller than
> Greater than
<= Smaller than or equal to
>= Greater than or equal to
== Equal to
!= Not equal to
& AND
| OR
! NOT

Example:

x[x >= 20 & x <= 30]

selects observations between 20 and 30.

Extracting variables with $

The $ operator extracts a variable (column) from a data frame.


cats$Bwt
cats$Sex
birthwt$age
Melanoma$time
UScereal$calories

Thus:

mean(cats$Bwt)

means “calculate the mean of the Bwt variable in the cats data frame.”

Rounding numbers

round()

Rounds a numerical value.

round(x, 1)

The second argument specifies the number of decimal places.

For example:

round(100 * prop.table(table(cats$Sex)), 1)

Comparing results

Intermediate results can be stored and compared.


sd_original <- sd(birthwt$age)

age_without_outlier <- birthwt$age[birthwt$age < 45]

sd_without_outlier <- sd(age_without_outlier)

c(
  original_SD = sd_original,
  SD_without_45 = sd_without_outlier,
  change = sd_without_outlier - sd_original
)

Percentage change:

100 * (sd_without_outlier - sd_original) / sd_original

This illustrates a useful general pattern:

  1. Calculate and store the original statistic.
  2. Modify or select the data.
  3. Calculate and store the new statistic.
  4. Compare the two.

Skewness

Base R does not provide a simple skewness() function. The exercises therefore calculated the standardized third moment:

mean((x - mean(x))^3) / sd(x)^3

Interpretation:

  • approximately 0 → symmetric
  • positive → right-skewed
  • negative → left-skewed

Example:


x <- Melanoma$time

skewness <- mean((x - mean(x))^3) / sd(x)^3
