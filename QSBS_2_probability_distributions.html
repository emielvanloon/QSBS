QSBS Practical 2 — Probability distributions

Introduction

In this practical we work with theoretical probability distributions rather than with data. All distribution functions we need (dnorm(), pbinom(), qpois(), …) live in the stats package, which is always loaded in R, so nothing has to be installed. Only in the last exercise do we compare a distribution with real data, and for that we are again using data from the MASS package, so we make sure this package is loaded.

library(MASS)

Every distribution in R comes with the same family of four functions. For the normal distribution these are:

Function Prefix What it returns
dnorm(x, ...) d = density the height of the curve at x (pdf for continuous, pmf for discrete distributions)
pnorm(q, ...) p = probability the cumulative probability \(P(X \le q)\), i.e. the area under the density up to q
qnorm(p, ...) q = quantile the inverse of pnorm(): the value q for which \(P(X \le q) = p\)
rnorm(n, ...) r = random n random draws from the distribution

The same holds for dbinom/pbinom/qbinom/rbinom, dpois/ppois/…, dunif/…, dlnorm/…, dgamma/… . Use ?Distributions to see the complete list.

Throughout the practical, keep the following distinction in mind:

  • for a discrete distribution d...() returns a genuine probability, \(P(X = k)\);
  • for a continuous distribution d...() returns a probability density. The probability of any single value is 0; only the area under the curve between two values is a probability. That area is exactly what p...() gives you.

Compact command reference

Below you find a list of the R commands that you can use to complete the exercises in this practical.

# Documentation
?Distributions
?dbinom
?dpois
?dnorm

# Discrete distributions (d = probability, p = cumulative, q = inverse cumulative)
dbinom(k, size = n, prob = p)
pbinom(q, size = n, prob = p)
qbinom(p, size = n, prob = p)

dpois(k, lambda = l)
ppois(q, lambda = l)
qpois(p, lambda = l)

# Continuous distributions (d = density, p = cumulative, q = inverse cumulative)
dnorm(x, mean = mu, sd = sigma)
pnorm(q, mean = mu, sd = sigma)
qnorm(p, mean = mu, sd = sigma)

dunif(x, min = a, max = b)
dlnorm(x, meanlog = mu, sdlog = sigma)
dgamma(x, shape = k, scale = theta)

# Upper tail: P(X > q) instead of P(X <= q)
pnorm(q, mean = mu, sd = sigma, lower.tail = FALSE)

# Plotting a continuous distribution
curve(dnorm(x, mean = 0, sd = 1), from = -4, to = 4)
curve(dnorm(x, mean = 0, sd = 2), add = TRUE, col = "grey50", lwd = 2)

# Plotting a discrete distribution
k <- 0:20
plot(k, dpois(k, lambda = 4), type = "h", lwd = 2)
points(k, dpois(k, lambda = 4), pch = 19)

# Reference lines, arrows and shading
abline(v = 2, col = "grey")
abline(h = 0.5, lty = 2)
segments(x0 = 0, y0 = 0.5, x1 = 2, y1 = 0.5)
polygon(x_coordinates, y_coordinates, col = "grey80")

# Numerical integration (area under a density)
integrate(dnorm, lower = -Inf, upper = 2)

# Sums and comparisons
sum(dbinom(0:24, size = 30, prob = 0.8))
all.equal(a, b)

# Comparing a distribution with data
hist(x, probability = TRUE)
lines(density(x), lwd = 2)
mean(x <= 2.5)
quantile(x, 0.90)

Exercise 1

A toxicological experiment (see Dormann, Sect. 3.4.3) places n = 30 water fleas (Daphnia) in water with a certain salt concentration. Each flea dies independently with probability p, so the number of deaths k follows a binomial distribution.

Plot the probability mass function of the binomial distribution for n = 30 and p = 0.8 for all possible outcomes k = 0, 1, ..., 30. Use a plot type that is appropriate for a discrete distribution. Add the mass functions for p = 0.5 and p = 0.2 to the same plot in a different colour.

Describe in words what changes when p changes, and explain why the curve for p = 0.5 is both wider and lower than the other two.

Exercise 2

Staying with the binomial distribution for n = 30 and p = 0.8, calculate:

  1. the probability that exactly 24 fleas die;
  2. the probability that at most 24 fleas die;
  3. the probability that more than 24 fleas die (do this without typing 1 - anywhere);
  4. the probability that between 20 and 25 fleas die (both limits included).

Then show, for part (b), that adding up the individual probabilities dbinom() gives you for k = 0, 1, ..., 24 returns exactly the same number as the single call to pbinom(). Explain in one sentence what this demonstrates about the relationship between d...() and p...().

Exercise 3

The Poisson distribution describes count data and has a single parameter \(\lambda\).

Plot the probability mass function of the Poisson distribution for \(\lambda = 1\), \(\lambda = 4\) and \(\lambda = 10\) in one figure, for k = 0, 1, ..., 20. Then make a second figure with the corresponding cumulative distribution functions. Describe what happens to the shape of the distribution as \(\lambda\) increases, and relate this to the Central Limit Theorem (Dormann, Sect. 3.1.1).

Next, suppose we observe the value k = 2 while \(\lambda = 10\). Calculate \(P(X = 2 \mid \lambda = 10)\) and \(P(X \le 2 \mid \lambda = 10)\) and explain, using the two figures, where you can read each of these two numbers off the graphs.

Exercise 4

Reproduce Fig. 3.3 of Dormann: plot the probability density of three normal distributions in one figure, N(0, 1), N(-1, 1.5) and N(0, 2), over the range \(-6\) to \(6\). Use curve() and label the axes properly. Make a second figure with the three corresponding cumulative distribution functions.

Use the figures to answer the following questions:

  1. Which parameter determines the position of the top of the curve, and which one the width?
  2. Why do all three density curves have a different height, even though each of them describes a complete distribution?
  3. In the cumulative plot, at which y-value do the three curves cross their own mean? Why?

Finally, for the standard normal distribution N(0, 1), calculate dnorm(2) and pnorm(2). Both numbers appear in the two figures, but they mean something very different. Explain the difference, and state which of the two is a probability.

Exercise 5

The q...() functions do the opposite of the p...() functions: you supply a probability and they return the value on the x-axis. This is why they are called quantile functions or inverse cumulative distribution functions.

  1. For the standard normal distribution, calculate the values that cut off the lower 2.5%, the middle (50%) and the lower 97.5% of the distribution.
  2. Verify that qnorm() really inverts pnorm() by feeding the output of one into the other for a value of your choice.
  3. Plot the inverse cumulative distribution function of the standard normal distribution, i.e. plot qnorm(p) against p, for p running from just above 0 to just below 1. Compare the shape of this figure with the cumulative distribution function you plotted in Exercise 4 and explain how the two are related.
  4. Now plot the inverse cumulative distribution function of the Poisson distribution with \(\lambda = 4\) in the same way. This figure looks like a staircase. Explain why, and explain what qpois(0.5, lambda = 4) means.

Exercise 6

Three continuous distributions with a restricted domain are the uniform, the log-normal and the gamma distribution (Dormann, Sects. 3.4.6, 3.4.7 and 3.4.9). Look up their R functions and their arguments with ?dunif, ?dlnorm and ?dgamma.

  1. Plot the density of the uniform distribution on the interval [2, 6] together with its cumulative distribution function. Explain the height of the density (0.25) and the fact that the cumulative distribution function is a straight line.
  2. Plot the density of the log-normal distribution with meanlog = 0 and sdlog = 1, and of the gamma distribution with shape = 2 and scale = 2, each over a sensible range. Describe the shape of both curves and state for which kind of measurement each would be a plausible model.
  3. For the log-normal distribution above, calculate the median with qlnorm() and the mean with the formula \(e^{\mu + \sigma^2/2}\). Mark both in the density plot. Why are they not equal, and why is exp(0) = 1 not the mean of this distribution?

Exercise 7

This exercise makes the link between the area under a density curve and the value of the cumulative distribution function explicit.

For the standard normal distribution, draw the density curve between \(-4\) and \(4\) and shade the area under the curve to the left of \(x = 2\). Then:

  1. Read pnorm(2) and check that it corresponds to the shaded area.
  2. Calculate the same area numerically with integrate().
  3. Shade instead the area between \(x = -1.96\) and \(x = 1.96\), and calculate that area both as a difference of two pnorm() values and with integrate().
  4. Explain in one or two sentences why we cannot do the same thing for a single point, i.e. why \(P(X = 2) = 0\) for a continuous distribution, whereas dnorm(2) is clearly larger than 0.

Shading an area requires the polygon() function, which is not entirely obvious. If you don’t know how to do this, you can use the code below.

Code 
# a grid of x-values covering the region to be shaded
x_shade <- seq(from = -4, to = 2, length.out = 200)

# the density at those x-values
y_shade <- dnorm(x_shade)

# the curve itself
curve(dnorm(x), from = -4, to = 4,
      xlab = "x", ylab = "probability density")

# the polygon: first along the curve, then back along the x-axis
polygon(x = c(x_shade, rev(x_shade)),
        y = c(y_shade, rep(0, length(y_shade))),
        col = "grey80", border = NA)

# redraw the curve on top of the shading
curve(dnorm(x), from = -4, to = 4, add = TRUE, lwd = 2)
