QSBS Practical 3 — Regression: generalised linear models

Introduction

In the previous practical we fitted a distribution to a sample: one set of parameter values for the whole data set. In this practical we take the next step: a parameter of the distribution is allowed to depend on a predictor variable. That is what a regression is (Dormann, Chap. 7 and 8).

The key ideas are:

  • A regression has a response \(y\) and a predictor \(x\): \(y \sim x\). We assume that every observation \(y_i\) is a random draw from a distribution whose parameter (usually the mean) is a function of \(x_i\), e.g. \(y \sim \mathrm{Pois}(\lambda = a + b x)\) or \(y \sim N(\mu = a + b x, \sigma)\).
  • The parameters \(a\) and \(b\) are found by maximum likelihood, exactly as in the previous practical: for every observation we calculate the (log) probability of \(y_i\) given \(\lambda_i = a + b x_i\) with a d...() function, we sum, and we search for the \(a\) and \(b\) that make this sum largest. glm() does this for us; optim() lets us do it by hand.
  • Distributions have restrictions (\(\lambda > 0\), \(0 < p < 1\)). The link function guarantees that the fitted values respect them: the model is linear on the link scale, e.g. \(\ln \lambda = a + bx\) (log link, Poisson) or \(\mathrm{logit}\, p = a + bx\) (logit link, binomial). The coefficients that glm() reports are on the link scale; to get back to the response scale you back-transform with exp() or plogis().
  • A categorical predictor (a factor) is turned into 0/1 dummy variables behind the scenes. The intercept is then the mean of the reference level (the alphabetically first level), and the other coefficients are differences from that reference — on the link scale.
  • The summary() of a GLM reports, for each coefficient, an estimate, its standard error and a test whether it differs from 0. It also reports the null deviance (variation without predictor) and the residual deviance (variation left over after the regression). The fraction \((D_0 - D_R)/D_0\) is the deviance explained. For Poisson and binomial models the ratio residual deviance / residual degrees of freedom should be about 1; if it is much larger, the data are overdispersed and a negative binomial model (glm.nb()) may be more appropriate.
  • To draw a regression line with a 95 % confidence band we ask predict() for fitted values and their standard errors on the link scale for a fine sequence of new \(x\) values, add and subtract twice the standard error, and back-transform.
  • Not everything fits into glm(): non-linear relationships and unusual distributions are fitted “by hand” with a likelihood function and optim(). The same approach lets us model other parameters of a distribution than the mean, e.g. a standard deviation that grows with \(x\).

The data for this practical come from the qsbsdata package, which is not on CRAN but on GitHub. Install it once with the remotes package (install remotes itself first if you don’t have it):

# Always plot first
plot(y ~ x, data = d)
boxplot(y ~ f, data = d)
plot(y ~ x, data = d, log = "y")           # logarithmic y-axis (= link scale for a log link)

# Fitting a GLM
fm <- glm(y ~ x, data = d, family = gaussian)
fm <- glm(y ~ x, data = d, family = poisson)               # log link
fm <- glm(cbind(succ, fail) ~ x, data = d, family = binomial)  # logit link
fm <- glm(y ~ x, data = d, family = gaussian(link = "log"))
fm <- glm(y ~ f, data = d, family = poisson)               # f is a factor
fm <- glm(y ~ x + f, data = d, family = poisson)
fm <- glm.nb(y ~ x, data = d)                              # negative binomial (MASS)
fm0 <- glm(y ~ 1, data = d, family = poisson)              # intercept-only ("null") model

# What is inside the result
summary(fm)
coef(fm)
confint(fm)
fitted(fm)
residuals(fm)
deviance(fm); fm$null.deviance; df.residual(fm)
logLik(fm); AIC(fm); BIC(fm)
fm$theta                                 # dispersion parameter of a glm.nb fit

# Deviance explained and overdispersion
(fm$null.deviance - deviance(fm)) / fm$null.deviance
deviance(fm) / df.residual(fm)

# How R codes a factor
levels(d$f)
model.matrix(~ f, data = d)
d$f <- relevel(d$f, ref = "other level")

# Back-transforming from the link scale
exp(coef(fm))          # log link
plogis(coef(fm))       # logit link
predict(fm, newdata = data.frame(x = 3))                     # link scale
predict(fm, newdata = data.frame(x = 3), type = "response")  # response scale

# Regression line with 95 % confidence band
xnew <- seq(min(d$x), max(d$x), length = 100)
pr <- predict(fm, newdata = data.frame(x = xnew), se.fit = TRUE)
lines(xnew, exp(pr$fit))
lines(xnew, exp(pr$fit + 2 * pr$se.fit), lty = 2)
lines(xnew, exp(pr$fit - 2 * pr$se.fit), lty = 2)

# Value of x at which p = 0.5 in a binomial GLM
dose.p(fm, p = 0.5)

# Maximum likelihood by hand
llfun <- function(parms) {
  mu <- exp(parms[1] + parms[2] * d$x)          # model on the link scale, back-transformed
  sum(dpois(d$y, lambda = mu, log = TRUE))
}
llfun(c(1, 0.1))                                # always test the function first
op <- optim(par = c(1, 0.1), fn = llfun, control = list(fnscale = -1),
            method = "BFGS", hessian = TRUE)
op$par; op$value; op$convergence
sqrt(diag(solve(-op$hessian)))                  # standard errors

# Likelihood profile: loop over a sequence of values
b1 <- seq(-1, 0, length = 100)
ll <- numeric(100)
for (i in 1:100) ll[i] <- llfun(c(1.8, b1[i]))
plot(b1, ll, type = "l")

# Drawing a fitted curve from hand-fitted parameters
curve(p["a"] * x / (p["b"] + x), add = TRUE)

# Useful helpers
tapply(d$y, d$f, mean); tapply(d$y, d$f, var)
table(); aggregate(); subset(); log(); log10(); which.max(); round(x, 3)
par(mfrow = c(1, 2)); legend(); abline(h = 0.5, lty = 3)

Exercise 1

The RIKZdat data set contains the number of macro-fauna species (Richness) found in 45 samples on nine Dutch beaches, together with the height of each sampling station relative to mean tidal level (NAP, in m). Stations with a high NAP are flooded less often; we expect fewer species there.

  1. Plot Richness against NAP. Which distribution is the natural first candidate for the response variable, and which link function goes with it (Dormann, Table 7.1)? Write down the model in the notation \(y \sim \mathrm{Dist}(\ldots)\).
  2. Fit the model with glm() and look at summary(). Report the two coefficients with their standard errors. On which scale are these numbers? Is the effect of NAP significant?
  3. Back-transform the intercept. What does the resulting number mean in words? Then calculate, from the coefficients and by hand, the expected species richness at NAP = -1, 0 and 1 m and check with predict(..., type = "response"). By what factor does the expected richness change for every metre increase in NAP?
  4. Calculate the deviance explained by the model from the null and residual deviance in the output. Compare the ratio residual deviance / residual degrees of freedom with 1 and comment.
  5. Draw the fitted curve with its 95 % confidence band on top of the data: make a sequence of 100 NAP values, use predict(..., se.fit = TRUE), add \(\pm 2\) standard errors on the link scale and back-transform with exp() before drawing. Explain why the band is not symmetric around the curve.
  6. Make the same plot with a logarithmic y-axis (log = "y"). What happens to the curve and to the band, and why (Dormann, Fig. 7.5)? Which of the two plots would you show in a report, and which to a statistician?

Exercise 2

The predictor can also be a factor. In slugs, the number of slugs was counted under 40 tiles in each of two grasslands (field: Nursery and Rookery).

  1. Make a boxplot or a table of the counts per field, and calculate the mean and the variance per field. What do you expect a Poisson GLM to give as coefficients, before you fit anything?
  2. Fit glm(slugs ~ field, family = poisson). Which field is the reference level, and why that one? Show that exp() of the intercept equals the mean of the reference field, and that exp() of the sum of the two coefficients equals the mean of the other field. What does exp() of the fieldRookery coefficient on its own represent?
  3. Look at model.matrix(~ field, data = slugs). Explain how the factor with two levels has become a column of 0s and 1s, and where the intercept lives in this matrix (Dormann, Sect. 7.2.1).
  4. Use relevel() to make Rookery the reference level and refit. Which numbers in the output change, and which stay the same (fitted means, deviances, AIC, p-value)?
  5. Compare the residual deviance with the residual degrees of freedom. Are the counts overdispersed? Also compare, for each field, the variance with the mean.
  6. Refit the model with glm.nb(). Report the estimate of the clumping parameter \(\theta\) and compare the two models with AIC. What happened to the standard error and the p-value of the field effect, and why (Dormann, Sect. 8.3)? Which model would you report, and is the difference between the fields significant?

Exercise 3

In wells, groundwater samples from n wells were taken in each of 20 areas on Long Island (New York); in y of the wells the solvent TCE was detected. The areas differ in median nitrate concentration (nitrate, mg/l) and in whether the area is sewered (sewer).

  1. Plot the proportion of contaminated wells y/n against nitrate. Why is a proportion not a good response variable for a gaussian GLM, and what should we use instead (Dormann, Sect. 8.1, the bioassay example)?
  2. Build the two-column response cbind(y, n - y) and fit a binomial GLM with nitrate as predictor. Report the coefficients. Which link function was used?
  3. Back-transform the intercept with plogis(): what is the fitted probability of contamination in an area with a nitrate concentration of 0 mg/l? What is it at 3 mg/l and at 7 mg/l? Do these calculations by hand from the coefficients and check them with predict(..., type = "response").
  4. Draw the fitted curve with a 95 % confidence band on top of the plot from (a). Remember that the standard errors are on the logit scale, so back-transform with plogis() after adding \(\pm 2\) SE.
  5. Use dose.p() to estimate the nitrate concentration at which half of the wells are contaminated. Compare this value with range(wells$nitrate) and explain why you should be reluctant to believe it.
  6. Now fit a binomial GLM with the factor sewer as the only predictor. Back-transform the intercept and the sum of the coefficients to two proportions, and check them against the pooled numbers of contaminated and clean wells in sewered and unsewered areas (aggregate() or tapply()). Compare the p-value of the sewer effect with the p-value of chisq.test() on the \(2 \times 2\) table of pooled counts (Dormann, Sect. 7.3.2). Are the two answers similar?

Exercise 4

The classic species–area relationship states that the number of species \(S\) on an island grows with the island’s area \(A\) as a power law: \(S = c A^z\). The gala data set gives the number of plant species on 29 Galápagos islands.

  1. Plot Species against Area, and then against log(Area). Which plot is more useful, and why?
  2. Show, by taking the logarithm of both sides of \(S = c A^z\), that the power law is a linear model on the log scale with predictor \(\log A\). Which family and link in glm() fit exactly this model without transforming the response?
  3. Fit glm(Species ~ log(Area), family = poisson). Read \(z\) directly from the output and calculate \(c\). Is \(z\) in the range 0.2–0.35 that is typical for islands?
  4. Calculate the ratio residual deviance / residual degrees of freedom. What do you conclude, and what does it mean for the standard errors and p-values in the Poisson output?
  5. Refit with glm.nb(). Compare the estimates of \(z\), their standard errors, and the AIC of the two models. Draw both fitted curves on the plot of Species against log(Area).
  6. A third option, common in older literature, is lm(log(Species) ~ log(Area)). Fit it and compare its \(z\) with the other two. Explain why the AIC of this model cannot be compared with the AICs from (e) (Dormann, Sect. 7.2.2), and what the model assumes about the noise that the Poisson and negative binomial models do not.

Exercise 5

In this exercise we calculate the Poisson regression of Exercise 1 by hand, following Dormann, Sect. 8.2.1. Take RIKZdat again, with Richness as the response and NAP as the predictor.

  1. Write a function llfun(parms) that takes a vector of two parameters (\(\beta_0\), \(\beta_1\)), calculates \(\lambda_i = e^{\beta_0 + \beta_1 \mathrm{NAP}_i}\) for every station and returns the sum of dpois(Richness, lambda, log = TRUE). Test it with llfun(c(1, 0)) and with llfun(c(1.8, -0.5)). Which of the two is more plausible?
  2. Fix \(\beta_0\) at 1.8 and calculate the log-likelihood for a sequence of 100 values of \(\beta_1\) between \(-1.5\) and \(0.5\) (a for loop or sapply()). Plot the result. This is a likelihood profile. Read off the best \(\beta_1\) with which.max().
  3. Now do the same on a grid of 100 × 100 combinations of \(\beta_0\) (between 1 and 2.5) and \(\beta_1\) (between \(-1.5\) and 0.5), store the values in a matrix and show it with contour(). Find the best combination with which(..., arr.ind = TRUE). Describe the shape of the contours: are the two parameters independent?
  4. Let optim() do the work: maximise llfun starting from c(1, 0) (remember fnscale = -1 and ask for the hessian). Compare op$par and op$value with the coefficients and logLik() of the GLM from Exercise 1. Did the optimiser converge?
  5. Calculate the standard errors from the Hessian with sqrt(diag(solve(-op$hessian))) and compare them with the standard errors in the GLM summary (Dormann, Side Note 6).
  6. Why does the likelihood surface in (c) have its maximum at an intercept that is not the log of the mean richness? What would the intercept be if you centred NAP first (NAP - mean(NAP))? Check it.

If you don’t know how to compute and plot the likelihood surface, you can use the code below.

Code 
beta0 <- seq(1, 2.5, length = 100)
beta1 <- seq(-1.5, 0.5, length = 100)
ll.m <- matrix(NA, nrow = 100, ncol = 100)
for (i in 1:100) {
  for (j in 1:100) {
    ll.m[i, j] <- llfun(c(beta0[i], beta1[j]))
  }
}
contour(beta0, beta1, ll.m, nlevels = 40,
        xlab = expression(beta[0]), ylab = expression(beta[1]))
best <- which(ll.m == max(ll.m), arr.ind = TRUE)
points(beta0[best[1]], beta1[best[2]], pch = 16, col = "red")

Exercise 6

Some relationships are not linear on any link scale. In beepollen, Harder and Thomson (1989) measured the proportion of a flower’s pollen that a bee removed (removed) as a function of how long it stayed at the flower (duration, s). A bee cannot remove more than all of the pollen, so we expect the curve to level off.

  1. Plot removed against duration. Fit a straight line with a gaussian GLM and draw it. Where does the line go wrong, and what would it predict for a visit of 200 s?
  2. A saturating alternative is the Michaelis–Menten function \(y = \dfrac{a\,x}{b + x}\) (Dormann, Sect. 8.2.2). What is the meaning of \(a\), and of \(b\)? Sketch (or reason out) what the curve looks like for \(a = 0.9\) and \(b = 15\).
  3. Write a likelihood function for the model \(\mathrm{removed} \sim N\!\left(\mu = \dfrac{a\,\mathrm{duration}}{b + \mathrm{duration}},\ \sigma\right)\) with a named parameter vector c(a = , b = , logsigma = ). Why do we estimate \(\log \sigma\) rather than \(\sigma\) itself? Test the function with c(a = 0.9, b = 15, logsigma = -2).
  4. Maximise it with optim(..., method = "BFGS", hessian = TRUE). Report \(\hat a\), \(\hat b\) and \(\hat\sigma\) with their standard errors, and use \(\hat a/\mathrm{SE}(\hat a)\) etc. as \(t\)-values to judge which parameters differ significantly from 0. Draw the fitted curve on the plot with curve().
  5. Calculate the AIC of this model by hand from op$value (how many parameters?) and compare it with AIC() of the straight line from (a). Which model is better, and by how much?
  6. The data contain queens and workers (queen). Extend the likelihood function so that \(a\) differs between the two castes (e.g. \(a = a_0 + a_1 \cdot \mathrm{queen}\)) and refit. Do queens remove more pollen than workers in the limit of long visits? Judge this from the estimate and standard error of \(a_1\) and from the AIC.

Exercise 7

The same model can often be fitted in several ways, and they do not give the same answer. Decay contains the amount of a substance (amount) that remains after time units, a textbook case of exponential decay \(y = y_0 e^{-kt}\).

  1. Plot the data on the normal scale and with a logarithmic y-axis. Which plot shows a straight line, and why?
  2. Route 1: fit lm(log(amount) ~ time). Route 2: fit glm(amount ~ time, family = gaussian(link = "log")). Route 3: maximise the log-likelihood of \(\mathrm{amount} \sim N(\mu = e^{\beta_0 + \beta_1 t}, \sigma)\) with optim(). Collect the estimates of \(\beta_0\) (i.e. \(\ln y_0\)) and \(\beta_1\) (i.e. \(-k\)) from the three routes in one table.
  3. Two of the three routes agree to several decimals. Which two, and why must they agree?
  4. Route 1 gives a different slope. Write down what each route assumes about the noise: is the scatter added on the log scale or on the original scale, and does it grow with the fitted value or not? Look at the plot from (a) to decide which assumption fits these data better.
  5. Draw the three fitted curves on the plot of amount against time. Where do they differ most? Calculate the half-life \(t_{1/2} = \ln 2 / k\) from each route.
  6. For Route 1, exp(fitted values) gives predictions on the original scale. Explain why these predictions are systematically lower than the mean of the data at a given time (hint: what is the mean of a log-normal distribution?).

Exercise 8

In the last exercise we model a distribution parameter other than the mean (Dormann, Sect. 8.4). Black bears in Minnesota were weighed at known ages (beargrowth). Restrict the data to young bears, bears <- subset(beargrowth, age <= 6), for which weight still increases roughly linearly with age.

  1. Plot wtkg against age and calculate the standard deviation of weight for each age with tapply(). What happens to the spread as the bears get older? Why does this violate the assumption of glm(wtkg ~ age, family = gaussian)?
  2. Fit that gaussian GLM anyway and note the coefficients, the dispersion parameter and the AIC.
  3. Write a likelihood function for the model \(\mathrm{wtkg} \sim N\!\big(\mu = a + b\,\mathrm{age},\ \sigma = e^{c + d\,\mathrm{age}}\big)\) with four parameters. Explain the role of the exponential. Test it with c(20, 10, 2, 0). What does \(d = 0\) correspond to?
  4. Maximise it with optim() (use method = "BFGS", hessian = TRUE; if it fails, change the starting values). Report the four estimates with their standard errors. Is \(d\) significantly different from 0?
  5. Calculate the AIC of the four-parameter model by hand and compare it with the AIC of the model in (b). Are the estimates of \(a\) and \(b\) very different between the two models? Which part of the output does change a lot, and why does that matter for a confidence band?
  6. Use the fitted values of \(\mu\) and \(\sigma\) to draw, on the plot from (a), the fitted mean line and the lines \(\mu \pm 2\sigma\) as a function of age. Roughly what fraction of the bears should fall between the outer lines? Check it with the data.
