QSBS Practical 4b — Regression diagnostics for GLMs

Introduction

In Practical 3 we fitted generalised linear models and interpreted their output. Fitting a model is, however, only half of the work: we also have to check whether the model is adequate for the data. That is what model diagnostics is about (Dormann, Chap. 9 and 10).

Dormann (Sect. 9.1) distinguishes five diagnostic steps. The first one, the analysis of the predictors, is descriptive and belongs to the exploratory phase of an analysis; in this practical we concentrate on the four steps that require a fitted model:

  1. Analysis of influential points. Some observations pull the regression line much harder than others. Cook’s distance measures, for each observation, how much all the fitted values change when that observation is left out. Values above 1 (Cook and Weisberg 1982) or above \(4/n\) (Bollen and Jackman 1990) deserve attention. An influential point is never simply deleted: we refit the model without it, compare the two fits, and report whether the conclusions are robust.
  2. Analysis of the dispersion. Poisson and binomial distributions fix the variance as a function of the mean, so the dispersion parameter is 1 by assumption. If the ratio residual deviance / residual degrees of freedom is much larger than 1 (say \(> 2\)) the data are overdispersed; if it is much smaller (say \(< 0.6\)) they are underdispersed. Overdispersion makes the standard errors too small (McCullagh and Nelder 1989), underdispersion makes them too large. The remedy is either a different distribution (e.g. negative binomial) or a quasi-likelihood model (quasipoisson, quasibinomial), which estimates the dispersion \(\hat\phi\) from the data and rescales all standard errors by \(\sqrt{\hat\phi}\).
  3. Analysis of the residuals. For a GLM the raw residuals \(y - \hat y\) are not useful, because their variance changes with \(\hat y\). We use standardised deviance residuals (rstandard()), which are corrected for the variance function, the dispersion and the leverage, and should look like a patternless cloud around 0 with a spread of roughly \(\pm 2\). We plot them against the fitted values on the link scale (predict(fm, type = "link")) and against each predictor, including candidate predictors that are not in the model.
  4. Analysis of the functional relationship between y and x. A GLM assumes that the relationship is linear on the link scale. Whether that is adequate can only be found out by comparing the model with an alternative: a model with a different error distribution, or a model extended with a polynomial term (poly(x, 2)). Nested models are compared with a likelihood-ratio test (anova(..., test = "Chisq")), non-nested models with AIC. Always draw the alternative fitted curves with their confidence bands on top of the data.

These four steps are not independent: a wrong functional form shows up as overdispersion and as a pattern in the residuals, and an influential point can create or hide a curvature. Diagnostics are therefore an iterative process, and after every change of the model the checks have to be repeated.

# Fitting the models (see Practical 3)
fm  <- glm(y ~ x, data = d, family = poisson)
fm  <- glm(cbind(succ, fail) ~ x, data = d, family = binomial)
fmq <- glm(y ~ x, data = d, family = quasipoisson)       # quasi-likelihood
fmq <- glm(cbind(succ, fail) ~ x, data = d, family = quasibinomial)
fnb <- glm.nb(y ~ x, data = d)                           # negative binomial (MASS)
fm2 <- glm(y ~ poly(x, 2), data = d, family = poisson)   # quadratic on the link scale
fm2 <- glm(y ~ x + I(x^2), data = d, family = poisson)   # same curve, non-orthogonal coding

# 1. Influential points
cd <- cooks.distance(fm)
plot(cd, type = "h"); abline(h = c(1, 4 / nrow(d)), lty = 2)
plot(fm, which = 4)                                      # built-in Cook's distance plot
which(cd > 4 / nrow(d))
fm_red <- update(fm, data = d[-c(4, 9), ])               # refit without rows 4 and 9
cbind(full = coef(fm), reduced = coef(fm_red))

# 2. Dispersion
deviance(fm) / df.residual(fm)                           # rough check: should be about 1
sum(residuals(fm, type = "pearson")^2) / df.residual(fm) # Pearson version, used by quasi-models
summary(fmq)$dispersion
summary(fm)$coefficients                                 # compare Std. Error columns
summary(fmq)$coefficients

# 3. Residuals
rSD <- rstandard(fm)                                     # standardised deviance residuals
eta <- predict(fm, type = "link")                        # fitted values on the link scale
plot(rSD ~ eta); abline(h = 0, lty = 3)
lines(lowess(eta, rSD), col = "red")                     # smoother to reveal a trend
plot(rSD ~ d$x); abline(h = 0, lty = 3)
boxplot(rSD ~ d$f); abline(h = 0, lty = 3)               # against a factor

# 4. Functional relationship: fitted curve with 95 % confidence band
xnew <- seq(min(d$x), max(d$x), length = 100)
pr <- predict(fm, newdata = data.frame(x = xnew), se.fit = TRUE)
plot(y ~ x, data = d)
matlines(xnew, exp(cbind(pr$fit, pr$fit - 2 * pr$se.fit, pr$fit + 2 * pr$se.fit)),
         lty = c(1, 2, 2), col = "black")                # exp() for a log link, plogis() for a logit link

# Comparing models
anova(fm, fm2, test = "Chisq")                           # nested models (likelihood-ratio test)
anova(fnb, fnb2)                                         # nested negative binomial models
AIC(fm, fm2, fnb)                                        # any models with a true likelihood
logLik(fm)
predict(fm, newdata = data.frame(x = 5), type = "response")

# Useful helpers
which.max(); order(); round(x, 3); sqrt(); nrow()
par(mfrow = c(1, 2)); legend(); abline(h = 0, lty = 3)

Exercise 1 — Influential points

In Practical 3 (Exercise 3) we modelled the proportion of contaminated wells in 20 areas on Long Island as a function of the nitrate concentration: glm(cbind(y, n - y) ~ nitrate, family = binomial, data = wells). Refit that model and call it fw.

  1. Calculate Cook’s distance for every area with cooks.distance(fw) and plot the values against the row number (type = "h"). Add horizontal reference lines at the two thresholds mentioned by Dormann (Sect. 9.1.2): 1 and \(4/n\). Which areas are flagged by each threshold?
  2. Look at the flagged area(s) in the data (wells[i, ]). Why does this particular area have such a large influence? Think about where it sits on the x-axis, how many wells it contributes, and how far its observed proportion is from the fitted curve.
  3. Refit the model without the most influential area (update(fw, data = wells[-i, ])). Put the coefficients and standard errors of the full and the reduced model side by side. By how much does the slope change? Does the conclusion about the effect of nitrate change?
  4. Draw the data (proportion y/n against nitrate, with point size proportional to n) and add the fitted curves of both models. Where do the two curves differ most, and why is that region exactly where you should be most careful with predictions?
  5. Write the sentence you would put in a report, following the two model sentences in Dormann Sect. 10.1.2. Explain why the influential area must not simply be dropped from the analysis.

Exercise 2 — Dispersion

In this exercise we look at over- and underdispersion, and at how a quasi-likelihood model corrects the standard errors.

  1. For the binomial model fw from Exercise 1, calculate the ratio residual deviance / residual degrees of freedom. Also calculate the Pearson version, \(\sum r_P^2 / \mathrm{df}\), with residuals(fw, type = "pearson"). Are the data over- or underdispersed? Is a binomial model with 20 areas on Long Island likely to satisfy the assumption that all wells in an area are independent draws with the same probability?
  2. Refit the model with family = quasibinomial and compare the summary() of the two fits. Which numbers are identical, which have changed, and what is the value reported as “Dispersion parameter”? Show that the standard errors of the quasi-model equal those of the binomial model multiplied by \(\sqrt{\hat\phi}\). What happens to the p-value of the nitrate effect?
  3. Now take the Mallard clutch-size data clutch (see ?clutch): the number of eggs (CLUTCH) in nests in artificial nesting structures, together with the Julian date on which the nest was found (date). Plot CLUTCH against date, fit a Poisson GLM CLUTCH ~ date and calculate the dispersion ratio. Are these data over- or underdispersed? Give a biological reason why clutch sizes might be less variable than a Poisson distribution predicts.
  4. Refit the clutch model with family = quasipoisson. In which direction do the standard errors move, and by what factor? What does this imply for the p-value and for the width of a confidence interval of the date effect? Explain in one sentence why underdispersion is, in a sense, a “luckier” problem to have than overdispersion.
  5. Finally, return to the Galápagos species–area model of Practical 3 (Exercise 4): glm(Species ~ log(Area), family = poisson, data = gala). The dispersion ratio is enormous. Fit a quasi-Poisson model and a negative binomial model (glm.nb()) and put the estimate and standard error of the log(Area) slope from all three models in one table. Which of the two remedies changes the estimate, and which one only changes the standard error? Why can the quasi-Poisson model not be compared with the others by AIC?

Exercise 3 — Residuals

We return to the macro-fauna data RIKZdat and the Poisson model of species richness against tidal height, glm(Richness ~ NAP, family = poisson, data = RIKZdat), which we call fr.

  1. Calculate the standardised deviance residuals with rstandard(fr) and the fitted values on the link scale with predict(fr, type = "link"). Plot the residuals against the fitted values, add a horizontal line at 0 and a smoother (lines(lowess(...))). What should this plot look like if the model were adequate? What do you actually see?
  2. Why do we plot against the linear predictor \(\hat\eta\) rather than against the fitted means \(\hat y\) on the response scale? Make the same plot with predict(fr, type = "response") on the x-axis and describe how the picture changes (hint: look at the spacing of the points along the x-axis).
  3. How many residuals lie outside \(\pm 2\), and which stations are they (which(abs(rSD) > 2))? For standardised residuals roughly 5 % should exceed \(\pm 2\) in absolute value; is that what you find? Is any single station also flagged by Cook’s distance?
  4. Plot the residuals against the predictor NAP. Is there a systematic pattern, e.g. a curvature? What kind of model change would this suggest? (We will test it in Exercise 4.)
  5. The data set contains more variables than NAP. Plot the residuals against exposure (a variable with three values, so use a boxplot with factor(exposure)) and against humus. Is there structure left in the residuals that one of these variables could explain? Extend the model with the variable that shows the clearest pattern, refit, and check whether the dispersion ratio and the residual plots have improved.

Exercise 4 — The functional relationship between y and x

The residual plot in Exercise 3 hinted that a straight line on the log scale may not be the best description of how richness depends on NAP. We now compare the model fr with two alternatives.

  1. Draw the data and the fitted curve of fr with its 95 % confidence band, following the recipe from Practical 3: a fine sequence of NAP values, predict(..., se.fit = TRUE) on the link scale, \(\pm 2\) standard errors, and exp() before drawing. Use matlines() to draw the three lines in one go.
  2. Alternative 1 — a different error distribution. Fit glm.nb(Richness ~ NAP, data = RIKZdat). Compare the estimate and standard error of the slope, the AIC and the value of \(\theta\) with the Poisson model. Add the negative binomial curve and confidence band to the plot from (a). Does the shape of the curve change, or mainly the width of the band?
  3. Alternative 2 — a polynomial on the link scale. Fit glm(Richness ~ poly(NAP, 2), family = poisson, data = RIKZdat) and compare it with fr by a likelihood-ratio test (anova(fr, fr2, test = "Chisq")) and by AIC. Is the quadratic term needed? Add the quadratic curve with its confidence band to the plot. Where do the linear and the quadratic curve differ, and in which region of NAP is the difference supported by data?
  4. Also fit the quadratic model with the explicit formula Richness ~ NAP + I(NAP^2). Show that the fitted values (and the AIC) are identical to those of the poly() model, but that the coefficients and their standard errors differ. Read Dormann’s footnote 9 in Sect. 10.1.5 and explain why one should prefer poly() for the test, but may prefer the explicit formula for reading off the shape of the curve.
  5. Combine both alternatives: fit glm.nb(Richness ~ poly(NAP, 2)) and compare it with the negative binomial straight-line model using anova(). Is the quadratic term still significant once overdispersion is accounted for by the negative binomial? Explain why the evidence for the curvature is weaker here than in (c).
  6. Predict, with each of the four models, the expected richness at NAP = 2.5 m (just above the observed range) and at NAP = -2 m (just below it). Where do the models disagree most, and what does this tell you about the difference between interpolation and extrapolation?
